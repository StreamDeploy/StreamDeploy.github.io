# StreamDeploy — archived showcase

A preserved copy of the StreamDeploy landing page, kept online as a showcase of
what the product was. **StreamDeploy has been discontinued.**

Live at <https://streamdeploy.github.io/>

Every path that reached a service which no longer exists has been deprecated:

- Header "Start Deploying" and the "Deploy Now" call to action render as
  disabled **Deprecated** buttons instead of linking to the sign-in page.
- The marketplace contact form no longer posts anywhere; its fields are
  disabled behind a notice.

This repository holds the built static output only. Source lives on the
`deprecated-showcase` branch of
[streamdeploy-landing](https://github.com/StreamDeploy/streamdeploy-landing/tree/deprecated-showcase).
